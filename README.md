# Portfolio — Jaimin Rana

Personal portfolio for [optimusbot.dev](https://optimusbot.dev/) — QA engineer & Python developer.

## Stack

- Static site: single-page `index.html` + assets
- GitHub Pages (CNAME → optimusbot.dev)
- Interactive labs: API playground, pipeline demo, bug triage

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Then visit `http://localhost:8080`.
